# Análisis de Membresías e Ingresos - Gimnasio 2024

## Descripción del Proyecto
Este proyecto integrador realiza un Análisis Exploratorio de Datos (EDA) sobre el comportamiento, hábitos e ingresos de un gimnasio fundado en Mendoza en enero de 2024.

## Objetivos Principales
* Medir el rendimiento mensual y la facturación total.
* Analizar la evolución de socios activos vs. inactivos.
* Determinar las actividades y métodos de pago más elegidos.
